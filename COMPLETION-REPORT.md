🚀 READY TO USE

To get started:
  1. Add coffee-cup-1.png to assets/images/
  2. Add coffee-cup-2.png to assets/images/
  3. Start PHP server:
     php -S localhost:8000
  4. Open browser to:
     http://localhost:8000
  5. Test the site!

To customize:
  - Colors: Edit :root in styles.css
  - Text: Edit index.php or components
  - Fonts: Update Google Fonts link
  - Sections: Create new components

To deploy:
  - Upload all files to web host
  - Ensure PHP 7.4+ support
  - Add images to assets/images/
  - Test on live domain
  - Monitor for errors
