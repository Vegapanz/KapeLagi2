## 🔧 Easy Customization

### Change Colors (1 place)
File: `assets/css/styles.css` lines 7-12
```css
:root {
    --color-dark-bg: #1A0F0A;      /* Change hero background */
    --color-navbar-bg: #E8E0D0;    /* Change navbar color */
    --color-text-primary: #F5F1E8; /* Change text color */
    /* ... etc ... */
}
```

### Change Fonts
File: `index.php` line 12
```html
<link href="https://fonts.googleapis.com/css2?family=NEWFONT&family=OTHERFONT&display=swap" rel="stylesheet">
```

### Change Text
Files: `components/navbar.php` and `components/hero.php`
- Edit directly in PHP files
- No compilation needed
- Changes reflect immediately

### Add More Sections
1. Create `components/section-name.php`
2. Include in `index.php`:
   ```php
   <?php include 'components/section-name.php'; ?>
   ```
3. Add CSS to `styles.css`
